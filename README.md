# AI-Powered Student Management System

An AI-powered web-based Student Management System developed using Python, Flask, SQLite, and Machine Learning. The system helps manage student information, attendance, marks, academic reports, and predicts student academic performance.

## 🚀 Features

- Student Registration
- Admin Login
- View Student Details
- Edit Student Information
- Student Attendance Management
- Marks Management
- AI-Based Academic Performance Prediction
- Student Performance Analysis
- PDF Report Generation
- Excel Report Generation
- SQLite Database Integration
- Responsive Web Interface

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Pandas
- NumPy
- Scikit-learn
- OpenPyXL
- ReportLab
- Machine Learning
- Git & GitHub
